# Portfolio Design System & Aesthetic Standard

## Visual Direction
- **Style**: Minimalist Editorial / Swiss Precision / Apple-like restraint.
- **Reference**: Clean typography with serif italic accents, generous whitespace, subtle rounded contours, clean hairline borders.
- **Core Stacks**: Next.js App Router, Tailwind CSS, Lucide Icons, Framer Motion, shadcn/ui foundation.

## Color Tokens
- Neutral Light Background: `bg-[#FAFAF9]`
- Foreground Title: `text-zinc-900`
- Subtitle & Metadata: `text-zinc-500`
- Border: `border-zinc-200/80`
- Interactive Hover: `hover:text-zinc-900 transition-colors duration-200`
- Badges: `bg-zinc-100 text-zinc-700 text-xs font-normal px-2.5 py-1 rounded-full`

## Guidelines
- Avoid heavy visual clutter. Let whitespace and typography do the heavy lifting.
- All icons strictly from `lucide-react`.
- Build components cleanly in separate modules for maintainability.
